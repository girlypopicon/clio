# CLIo speech-to-text Worker

A tiny Cloudflare Worker that turns short audio clips into text using Workers AI
(`@cf/openai/whisper-large-v3-turbo`). CLIo sends it each spoken sentence while you dictate.
You deploy it to your own Cloudflare account; there is no server to run.

## Deploy (about 5 minutes)

You need a free Cloudflare account and Node.js 18+.

```bash
cd worker
npm install --save-dev wrangler
npx wrangler login      # opens a browser to sign in
npx wrangler deploy     # prints https://clio-stt.<your-subdomain>.workers.dev
```

Then in CLIo: **Settings > Voice > Whisper server**, paste the `workers.dev` URL
(no path, no API key needed). Leave **Local only** unchecked.

If CLIo cannot reach the Worker it automatically falls back to the local Whisper model.

## Check it works

```bash
curl https://clio-stt.<your-subdomain>.workers.dev/      # {"ok":true,"service":"clio-stt"}
```

Run the tests (no Cloudflare account needed): `node --test test/handler.test.mjs`
Run locally against real Workers AI: `npx wrangler dev` (uses your account, remote AI).

## Request / response

```
POST /            (or /v1/audio/transcriptions)
X-Clio-Install: <uuid>            random per-install id CLIo generates on first run
Content-Type: multipart/form-data
  file      16 kHz mono 16-bit WAV, at most 2 MB (a few seconds per clip)
  language  optional, default "en"
  prompt    optional vocabulary hint (names and terms), max 600 chars

200 {"text": "..."}
400 bad/missing id or file     413 too large     415 not WAV
429 rate limited               502 Workers AI failed
```

The Worker base64-encodes the WAV and calls `env.AI.run(model, { audio, language, initial_prompt })`.
The model id, input and output fields come from Cloudflare's Workers AI docs; double-check them
there if Cloudflare renames the model.

## What the protection is (and is not)

- **Rate limiting, not authentication.** The install id is generated by each CLIo install, so anyone
  can make up ids. Limits are `30 requests/min` per id and `120/min` per IP (see `wrangler.toml`).
  They are approximate and enforced per Cloudflare location.
- Anyone who learns your Worker URL can send audio to it and use your Workers AI quota
  (billed per audio minute, roughly $0.0005/min at the time of writing; the free tier has a daily allowance).
  Keep the URL private, or set a spend alert in the Cloudflare dashboard.
- If you ever ship this widely, move to per-user tokens (e.g. signed by an account service) before
  publishing the URL.
- The Worker does not store or log audio, prompts or install ids.
